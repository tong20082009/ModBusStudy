# ModBusStudy

## 温控设备上位机

模拟：

一个温控箱：

设备提供：

| 地址    | 含义   | 类型    |
| ----- | ---- | ----- |
| 40001 | 当前温度 | float |
| 40002 | 目标温度 | float |
| 00001 | 加热状态 | bool  |
| 00002 | 启动按钮 | bool  |

目标：

做一个软件：

```
+-----------------------+
| 温控设备监控系统       |
+-----------------------+

当前温度:
25.6℃

目标温度:
80℃

状态:
加热中

[启动]
[停止]

实时曲线
报警记录
```
